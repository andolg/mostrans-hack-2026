# Генератор демонстрационного прогноза

Генератор читает нормализованные ID маршрутов, сегментов и остановок из GeoJSON и создаёт воспроизводимые прогнозы. Используются два суточных гауссовых пика, эффекты дня недели, сезонность, плавный профиль загрузки вдоль маршрута и растущая с горизонтом неопределённость.

Дополнительные Python-пакеты не нужны.

```powershell
python tools/mock-data/generate_forecasts.py `
  --osm-dir frontend/public/data/osm `
  --output frontend/public/data/mock `
  --seed 42 `
  --start-date 2026-09-23
```

Одинаковые входные GeoJSON, seed и дата дают одинаковый результат. Эти файлы — временный источник данных; интерфейс обращается к ним через `ForecastRepository`, поэтому их можно заменить REST API без изменения компонентов.
