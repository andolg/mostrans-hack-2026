# Архитектура фронтенда

Vite собирает React/TypeScript SPA. В Docker nginx раздаёт приложение и локальную геометрию OSM, а запросы `/api/*` перенаправляет в FastAPI. При разработке ту же роль выполняет Vite proxy. Карта построена на MapLibre, график — на ECharts, запросы к API ведутся через TanStack Query.

## Данные и взаимодействие

`/api/metadata` задаёт список маршрутов и границы истории. Первоначально выбран месяц сразу после `historical_end`. Пользователь меняет начало и исключающую дату конца свободно; начало до `historical_start` вызывает ошибку интерфейса. Шаг `hour|day|month` передаётся в `/api/boardings` вместе с диапазоном. Ответ содержит только число посадок по маршруту и интервалу с пометкой `actual` или `forecast`. Экспорт использует `/api/boardings/export` с теми же параметрами.

На временной шкале отображается ряд выбранного маршрута. Факты и прогнозы окрашены разными цветами. Клик в области графика или слайдер выбирает один интервал из ответа API и обновляет значения на карте. Цвет линии каждого маршрута определяется его значением для выбранного интервала относительно минимума и максимума этого же маршрута за весь видимый период при текущем шаге. Остановки OSM — только географические ориентиры, без посадок или других показателей.

## Геометрия

Линии и остановки читаются из `frontend/public/data/osm` без использования браузерного кэша, чтобы обновлённая геометрия появлялась после перезагрузки страницы. Несколько OSM relations для направлений объединяются в интерфейсе по `routeRef`, который соответствует числовому `route` API. Если геометрии маршрута нет в GeoJSON, интерфейс сообщает об этом в панели; ряд и экспорт остаются доступны. Для обновления GeoJSON используются [OSM-утилиты](../../tools/osm/README.md).
